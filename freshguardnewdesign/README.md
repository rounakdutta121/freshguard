# FreshGuard New Design — WordPress Theme

Exact WordPress / Elementor copy of `freshguard.html` — lime palette (`#8fc640`), problem-focused images, matching layout, motion, and responsiveness.

## Install
1. Copy the `freshguardnewdesign` folder into `wp-content/themes/`
2. Appearance → Themes → activate **FreshGuard New Design**
3. Install **Elementor**
4. Click **Setup / Repair Homepage** in the admin notice
5. Open the site — full landing page matching `freshguard.html`
6. Home → **Edit with Elementor**

## Elementor widgets
- **FreshGuard Full Landing** — entire page in one widget
- **FG: Hero / Welcome / Services / Europe / Assessment / Partners / Contact / Articles** — one section per widget, all text and images editable

Setup rebuilds 8 full-width containers (Hero → Articles). Welcome includes the stats bar + About section, same as the HTML.
