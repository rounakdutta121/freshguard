# FreshGuard WordPress Theme v2

Exact copy of `index.html` — layout, colors, images, responsiveness.

## Install
1. Upload `freshguard-wp-theme.zip` via Appearance → Themes → Upload
2. Activate **FreshGuard**
3. Install **Elementor**
4. Click **Setup / Repair Homepage** in the admin notice
5. Open site → full landing page
6. Home → **Edit with Elementor**

## Elementor widgets
- **FreshGuard Full Landing** — entire page in one box
- **FreshGuard Section** — Hero / Welcome (editable text + images) + other exact sections

## Folder
`freshguard/` (theme directory name)
